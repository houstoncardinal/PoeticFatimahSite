# Admin Guide - Poetically Fatimah

## How to Add Fatimah's Poetry & Content

### Login to Admin Dashboard

1. Visit: `/admin/login`
2. **Credentials:**
   - Username: `admin`
   - Password: `admin123`
3. Click "Log In"

### Managing Poems

1. From the admin dashboard, click **"Poems"**
2. Click **"Add Poem"** button
3. Fill in the form:
   - **Title**: Poem title (e.g., "Soft is Not Small")
   - **Slug**: Auto-generated URL-friendly version
   - **Poem Text**: The full poem body
   - **Excerpt**: Short preview (optional)
   - **Collection**: Select from existing collections
   - **Themes**: Comma-separated (e.g., "Healing, Strength, Vulnerability")
   - **Audio URL**: Link to poem recording (optional)
   - **Image URL**: Cover image link (optional)
4. Click **"Create Poem"**

### Managing Collections

Collections group poems together (like "Healing", "Becoming", "City Light").

**Current Collections:**
- Healing - Poems about healing and self-discovery
- Becoming - Reflections on identity and growth
- City Light - Urban poetry

### Managing Events

Add Fatimah's performances, workshops, and speaking engagements.

### Managing Products

Add books, prints, audio collections, and other items for the shop.

### Managing Journal

Add blog posts, reflections, and announcements.

### Tips for Adding Content from Instagram

Since we can't automatically import from Instagram:

1. **For each Instagram post with poetry:**
   - Copy the poem text
   - Save any associated image
   - Add as a new poem in the admin
   
2. **For performance videos:**
   - Note the video URL
   - Add as an event (past or upcoming)
   
3. **For product promotions:**
   - Screenshot or note product details
   - Add to Products section

### Social Media Integration

Update the Links in Bio page (`/links`) by modifying the seed data or adding a Links admin page.

### Content Organization Tips

- **Use Collections** to organize poems by theme
- **Add Themes** to make poems searchable
- **Include Excerpts** for better preview cards
- **Add Audio** when available for full experience

## Need Help?

The admin interface saves everything to the database automatically. All changes are live immediately on the public site!
